## Enunciado: Lendo o sensor de presença

O projeto está usando um sensor PIR para quando detectar alguma movimentação ele acender um LED vermelho.

- O Arduino lê o estado do sensor PIR pelo **pino 7**
- Controla o LED Vermelho pelo **pino 6**

## Materiais necessários

| Qtd | Componente |
|-----|------------|
| 1 | Placa Arduino UNO |
| 1 | Cabo USB |
| 1 | Protoboard |
| 2 | Resistor de 200 Ω ou 220 Ω |
| 1 | LED vermelho difuso de 5 mm |
| 1 | Sensor PIR|
| — | Fios de jumper macho-macho |
